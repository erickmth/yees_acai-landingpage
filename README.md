# 🍧 Yees Açaí - Landing Page


Landing page profissional desenvolvida para a **Yees Açaí**, uma lanchonete especializada em açaí localizada em Campo Largo/PR. O projeto foi criado com foco em conversão, experiência mobile e identidade visual marcante.

## 🚀 Tecnologias Utilizadas

- **HTML5** - Estrutura semântica
- **Tailwind CSS** - Estilização rápida e responsiva
- **JavaScript** - Interatividade e animações
- **Alpine.js** - Funcionalidades reativas (menu mobile)
- **AOS (Animate on Scroll)** - Animações suaves durante o scroll
- **Font Awesome** - Ícones vetoriais

## ✨ Funcionalidades

- ✅ Design 100% responsivo (mobile, tablet, desktop)
- ✅ Menu mobile interativo com Alpine.js
- ✅ Animações parallax e floating nos elementos
- ✅ Efeitos de hover e transições suaves
- ✅ Integração direta com WhatsApp para pedidos
- ✅ Link para localização no Google Maps
- ✅ Galeria de produtos com imagens otimizadas
- ✅ Vídeo autoplay da equipe (sem controles)
- ✅ Footer com informações de contato e desenvolvedor

## 🎨 Destaques Visuais

- Gradientes personalizados com cores da marca (roxo e verde)
- Efeito "glassmorphism" nos cards
- Animações floating nos elementos principais
- Tipografia moderna com Plus Jakarta Sans
- Sombras e blur effects para profundidade

## 📱 Responsividade

Adaptado para todos os tamanhos de tela:
- 📱 Smartphones (320px - 480px)
- 📱 Tablets (768px - 1024px)
- 💻 Desktops (1025px+)
